# Himangshu Music 1.4.23

## Highlights

- Add original artwork banners to mood and genre browsing, with matching category art and a general fallback.
- Build a timed listening session from an existing playlist, with a preview and explicit Play action; the source playlist is unchanged.
- Add AI playlist sequencing: describe a listening arc, preview the reordered tracks, and apply it only when you choose.
- Add a lyrics-aware song companion for grounded theme summaries, selected-line explanations, and listener questions using the configured AI provider.
- Create a 15-song “continue this vibe” mix from a song using only its title and artist; it is saved to the library only when requested.
- Change the Android application ID to `com.himangshu.rajgogoi.music`. Android treats it as a separate app from the previous package, so existing app data does not transfer automatically.
