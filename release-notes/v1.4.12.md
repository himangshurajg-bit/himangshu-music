# Himangshu Music 1.4.12

## Highlights

- Restore the v1.4.8 app baseline, then apply compatible changes from the latest Echo Music source while retaining Himangshu Music branding and existing player features.
- Add ten task-aware study listening presets, with a custom focus timer and optional 25/5 Pomodoro timer. The searches are not vetted playlists; see [the evidence and limits](https://github.com/himangshurajg-bit/himangshu-music/blob/v1.4.12/docs/study-focus-evidence.md).
- Add an in-app dimmed always-on player screen with clock, track details and playback controls. It keeps the screen awake only while open and is not Android’s system AOD.
- Add a real-time stereo DSP 8D effect with moving stereo pan, width, bass, optional delay/reverb, speed/motion controls, and exact PCM16 bypass. It is not HRTF/binaural 360-degree audio; device, headphone route, and USB bit-perfect/offload behavior need separate testing.

## Limitations

The music searches are not individually reviewed or performance-validated; results vary, and silence may work better for some tasks. The 8D effect is stereo DSP rather than HRTF/binaural positioning. No on-device or headphone hardware test is claimed.
