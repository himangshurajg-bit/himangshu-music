# Himangshu Music 1.4.11

This release adapts the compatible playback, queue, artwork, search, and link-handling changes from the upstream Echo Music v1.4.8 update, alongside Himangshu Music's existing custom features and Settings performance fix.

## Highlights

- If a lossless add-on stream fails, playback falls back to YouTube from the same position instead of stopping.
- FLAC tracks can be seeked without restarting; temporary HTTP 429/503 errors no longer mark tracks unplayable.
- Cover art stays sharp when maximum-resolution thumbnails are unavailable, and animated canvases are shown only when supplied by supported real sources.
- Tracks started from search or a link now start their own radio without an unrelated automix track appearing first.
- Upcoming tracks preload in actual play order, including shuffle, while adaptive quality and add-on matching are more reliable.
- Search results appear while typing, with add-on results integrated into the main search.
- External links use a safe chooser or copy-to-clipboard fallback when no browser can open them.

## Playback fixes

- A failed add-on stream, including a temporary host failure, can continue from YouTube at the same playback position; after a 429 response, the add-on waits two minutes before retrying.
- Seeking FLAC files without a seek table no longer restarts playback. Prefetch now records file length and discards cached heads whose length is unknown.
- Temporary HTTP 429/503 errors preserve cached audio and resolved links, then retry after 3, 6, 12, and 24 seconds before giving up.
- Initial loading is no longer counted as a playback stall: a stall counts only after playback has begun since the last seek or track change.
- Cached audio now records whether it came from an add-on or YouTube and is discarded when the selected source changes, preventing the wrong stream from playing.
- Lossless prefetch is capped at the first 8 MB of each file and pauses for two minutes after a 429, avoiding whole-file requests that trigger rate limits.
- Playback error messages now distinguish a busy server, an expired link, and age/login restrictions instead of labeling every HTTP failure as age-restricted.

## Queue and radio

- A track's own radio no longer starts behind an unrelated automix track when playback begins from search or a link.
- Automix no longer queues the same pick repeatedly: it waits three seconds and fills only a genuinely empty queue.
- Related-song radio no longer appears before the first page of a queue started from one track.
- Tracks from an earlier queue's automix pool no longer leak into a newly started queue.

## Player and artwork

- When a maximum-resolution thumbnail is unavailable, cover loading falls back successively through `sddefault`, `hq720`, and `hqdefault` rather than showing a soft, letterboxed image.
- Album tracks retain their sharp still cover instead of showing a zoomed, blurred copy.
- Canvases are limited to Apple Music, Spotify, or Tidal sources; YouTube fallbacks no longer replace covers with canvases, and audio-only or visualizer uploads are excluded from artist-page fallback results.
- Lossless format labels show the sample rate rather than a stale YouTube bitrate (for example, incorrectly showing FLAC at 160 kbps).

## Navigation

- Opening an external link no longer crashes when Android has no browser able to handle it. The app offers a chooser or copies the link with a brief message.
- The update action opens Himangshu Music's GitHub Releases page using the same safe link handling.

## Improvements

- **Adaptive quality:** Non-lossless modes use the add-on only when measured throughput is at least 3 Mbit/s and it has not stalled in the past five minutes. Auto switches to YouTube's low quality below 400 kbit/s.
- **Preloading:** Upcoming tracks preload in actual play order, including when shuffle is enabled.
- **Add-on matching:** Tracks uploaded under another channel with titles in `Artist - Title` form are searched using both title parts.
- **Search:** Add-on results are searched alongside YouTube and appear as you type. The Add-ons section is removed; it appears first only when add-on audio is preferred.

## Technical changes

- Updated version to 1.4.11 (Android version code 172), retaining Himangshu Music's release identity and download links.
- Moved automix queue filling into a `LaunchedEffect` keyed to playback skip state and the first automix ID.
- Centralized cover fallback behavior so the image-loader interceptor and player cover use the same logic.
- Added safe external-URI handling and Android 11+ package-visibility queries for browser discovery.
- Added release-build logging for why a track does not use the add-on.
- Retained code and resource shrinking and reduced Settings rendering overhead by removing repeated live blur layers while keeping translucent cards.

The upstream changes were adapted from Echo Music v1.4.8; original licensing and copyright notices remain in the source.
