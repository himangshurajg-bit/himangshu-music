# RajTune 1.4.18

## Highlights

- Improve queue matching for addon tracks using title, artist, and duration, and rank similar songs using available listening-history and mood/genre signals; uncertain matches fall back instead of guessing.
- Add queue autoplay controls and Familiar/Discover artist filters.
- Add a Quick Settings tile for the dim in-app AOD player, with artwork and subtle ambient updates. This is not Android system-level always-on display.
- Refresh search discovery categories with live YouTube Music mood and genre browse links.
- Improve Spotify playlist-import login initialization. Spotify support here imports playlists and liked songs; it does not stream Spotify audio.
