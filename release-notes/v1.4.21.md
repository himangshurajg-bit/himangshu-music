# RajTune 1.4.21

## Highlights

- Add optional Firebase Analytics setup for signed releases, with instructions for viewing active app instances.
- Analytics reporting is enabled only when the repository secret `FIREBASE_GOOGLE_SERVICES_JSON_BASE64` is configured; without it, the APK still builds but does not send Firebase Analytics events.
- Active-user figures are estimates of active app instances, not verified counts of unique people or downloads.
