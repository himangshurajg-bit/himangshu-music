# RajTune 1.4.25

## Highlights

- Add offline stem splitter: split a local file into vocals, drums, bass and other. Model downloads once inside the app, then works offline. Models are not bundled in the APK.
- Add cloud stem-splitting backend (services/stem-cloud) with authenticated jobs, progress, cancel and stem download. App cloud mode stays off until a server endpoint and token are configured; audio never uploads silently.
- Fix R8/minify for ONNX Runtime.
