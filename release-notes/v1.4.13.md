# RajTune 1.4.13

## Highlights

- Rebrand the app as RajTune across the app name, settings, share surfaces, localized labels, project documentation, and store listing.
- Set the coral-and-white treble clef as the default launcher icon; keep the gold-and-blue design and add two monochrome options.
- Keep the existing launcher choices and add the requested clef designs from the supplied icon images.
- Add glass styling and a live album-art ambient-light option.
- Add a YouTube-song menu handoff to YTDLnis for audio downloads; the existing in-app download path is unchanged.

## Notes

YTDLnis is a separate app and must be installed to use the handoff. The icon and app-name changes have not yet been tested on a physical device.
