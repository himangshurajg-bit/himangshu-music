# RajTune 1.4.27

## Professional stem mixer (offline only)

- Add per-stem controls for vocals, bass, drums, other/music and future stems: play/pause all, A/B original compare, solo, mute, volume/gain fader, pan, playback speed/pitch, loop/trim, export/share quality.
- Add real 6-band professional equalizer (low/high shelf + peaking, frequency/gain/Q persisted, per-stem + master) and presets (Flat, Vocal Boost, Bass Boost, Drum Punch, Warm, Bright, Club, Gentle Low Cut) with save/restore per stem.
- Add waveform display per stem, level percentages, mix presets, project/session auto-save, and high-quality mix-down export (WAV 16-bit and MP3 320/192/128 kbps).
- Real audio paths: live playback uses Media3 StemGainPanAudioProcessor + CustomEqualizerAudioProcessor per stem; export uses FFmpeg filter graph with volume, pan, equalizer, amix.
- Scope (offline only): the mixer/EQ/FFmpeg mix-down apply to on-device offline stems only. Cloud stems keep the existing simple Play list; the splitter screen shows an offline-mixer notice in Cloud mode and the mixer stays disabled there. No cloud/web EQ was added and no extra upload is performed by the mixer.

## StemDeck-style studio parity (offline only)

- Six-lane studio view (vocals, drums, bass, guitar, piano, other). Be honest about what the current 4-stem on-device model outputs: vocals/drums/bass/other are separately separated; guitar/piano lanes are labelled "Routed from Other — not separately separated" and are not faked.
- Practice vs Advanced modes: Practice keeps mixer/speed/key/loop; EQ, saved presets and loudness are Advanced-only.
- Key transposition (+/-12 semitones) wired to the same master pitch path as live playback and FFmpeg export.
- Click + count-in for exports (BPM 40-240, 2/3/4/6 beats per bar, 0-4 count-in bars, generated locally as WAV and mixed into the export). Live metronome is not claimed: it needs a beat grid RajTune does not have.
- Loudness targets for mix-down via FFmpeg loudnorm (None, Streaming -14 LUFS, Album -16 LUFS, Broadcast -23 LUFS).
- Export stems as ZIP (vocals.wav, drums.wav, bass.wav, other.wav) to Music/RajTune Stems, offline.
- Note on StemDeck: StemDeck (AGPL-3.0-only, Demucs htdemucs_6s weights) was audited as a feature reference only. No StemDeck code, assets or model weights were copied into RajTune (AGPL into GPL-3.0 is incompatible, and the Demucs 6-stem weights are not shippable). Features above are RajTune's own implementations.
