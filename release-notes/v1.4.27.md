# RajTune 1.4.27

## Professional stem mixer (offline only)

- Add per-stem controls for vocals, bass, drums, other/music and future stems: play/pause all, A/B original compare, solo, mute, volume/gain fader, pan, playback speed/pitch, loop/trim, export/share quality.
- Add real 6-band professional equalizer (low/high shelf + peaking, frequency/gain/Q persisted, per-stem + master) and presets (Flat, Vocal Boost, Bass Boost, Drum Punch, Warm, Bright, Club, Gentle Low Cut) with save/restore per stem.
- Add waveform display per stem, level percentages, mix presets, project/session auto-save, and high-quality mix-down export (WAV 16-bit and MP3 320/192/128 kbps).
- Real audio paths: live playback uses Media3 StemGainPanAudioProcessor + CustomEqualizerAudioProcessor per stem; export uses FFmpeg filter graph with volume, pan, equalizer, amix.
- Scope (offline only): the mixer/EQ/FFmpeg mix-down apply to on-device offline stems only. Cloud stems keep the existing simple Play list; the splitter screen shows an offline-mixer notice in Cloud mode and the mixer stays disabled there. No cloud/web EQ was added and no extra upload is performed by the mixer.
