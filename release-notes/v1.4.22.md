# RajTune 1.4.22

## Highlights

- Add an Android system music screensaver with current-track artwork, playback progress, controls and synchronized lyrics. Enable it in Android Settings → Screen saver.
- Improve the in-app dimmed player with artwork, progress, playback controls, a clock and lyrics.
- Make Spotify sign-in more resilient with bounded retries for transient network errors, rate limits and server errors. This does not add Spotify audio streaming.
