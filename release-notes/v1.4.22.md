# Himangshu Music 1.4.22

## Highlights

- Add Settings controls to view storage use, set song and image cache limits, and clear cached media.
- Add an Android system music screensaver with track artwork, playback progress, controls and synced lyrics. Enable it in Android Settings → Screen saver.
- Improve the in-app dimmed player with artwork, progress, playback controls, a clock and lyrics.
- Make Spotify sign-in more resilient with bounded retries for transient network errors, rate limits and server errors. This does not add Spotify audio streaming.
- Fix a crash when mood or genre results contain duplicate categories.
