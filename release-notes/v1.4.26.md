# Himangshu Music 1.4.26

## Highlights

- Fix **Listen Together**: the client now speaks Protobuf, matching the live server. Previously it sent JSON, so rooms would not connect.
- Bring compatible updates from Echo Music's latest main and rebrand the cross-device feature from Echo Connect to **Himangshu Connect** everywhere — Settings, Player menu, audio output sheet, pairing prompt, search, docs and icon (icon resource renamed to `ic_himangshu_connect`, route to `settings/himangshu_connect`).
- Port upstream fixes: Home hero carousel and Library spacing, collapsing bottom navbar with inline MiniPlayer, liked-songs / playlist-sort / local-likes sync fixes, podcast metadata in Continue Listening, and grouped settings.
- Preserve Himangshu Music identity and existing features: applicationId stays `com.himangshu.rajgogoi.music`. The upstream Echo desktop promo banner is not included. Stem splitter, AI companion, 8D audio and custom shortcuts are unchanged.

## Notes

- **Himangshu Connect** links Himangshu Music (Android) with Echo Music Desktop over local Wi-Fi for playback handoff, remote control and sync. The desktop client still uses its own name.
- Full guide: `docs/HIMANGSHU_CONNECT.md`.
